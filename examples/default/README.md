# Default project

This project is copied into First session on a fresh installation, and into
new projects. `controls-demo.strudel` opens first; press Play to start sound.
All sounds in this project are synthesized and need no sample downloads.

- `controls-demo.strudel`: drums, bass and lead with knobs, switches, enums,
  sliders and reorderable effects.
- `first-light.strudel`: composition importing `instruments/glass.strudel`.
- `instruments/glass.strudel`: reusable bell voice, also playable on its own.
- `sketches/soft-steps.strudel`: short melodic pattern.
- `sketches/low-tide.strudel`: slow bass pattern.
