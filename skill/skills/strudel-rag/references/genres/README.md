# Electronic-music genre guides

[Back to the SKILL](../../SKILL.md)

Twenty practical starting profiles for electronic-music composition in Wien. This is a representative selection, **not a measured top-20 ranking**, a complete taxonomy, or a set of strict genre boundaries. All tempos and recipes are locally authored creative defaults, not retrieved source evidence. User intent and the existing project take precedence.

## Select a guide

Read one primary guide; for an explicit hybrid, optionally read one secondary guide. Choose 2–4 primary identity anchors before writing notes. Each guide contains a working brief, groove and bass instructions, palette, composition recipe, arrangement options, quality checks, and lookup prompts.

## Shared instructions

- Work in musical beats and bars first. A 4/4 bar contains four quarter-note beats; each beat can be divided into four sixteenths. Any grid or placement is a musical recipe, **not Strudel code**. Verify tempo and bar-to-cycle mapping before implementation; half-time feel does not automatically halve the transport tempo.
- Use the numbered recipe to establish drums or pulse, bass, and one identity-bearing motif before adding layers. Match arrangement scale to the request: a short loop needs variation, not an entire song structure.
- Keep kick and bass attacks/tails compatible. Separate sub, harmonic body, and foreground roles; more distortion or reverb is not a substitute for arrangement.
- Search the guide's lookup prompts with `api`, `musical`, or `example` intent as appropriate, following [SKILL section 1](../../SKILL.md#1-availability-and-evidence). Fetch critical parent documents and verify syntax, timing, sound sources, and sample permissions. Do not invent methods or assume that samples are installed.
- These files ship with the skill and are read locally. They are **not automatically ingested or searchable through the RAG service**, and reading one does not establish API or audio verification. Keep `references/` with `SKILL.md` when installing or copying the skill.
- For subgenres, choose the nearest starting profile and state the adaptation: e.g. minimal techno from techno, liquid DnB from drum & bass. Do not conflate electro with electro house, jungle with every DnB style, or hardcore here with punk. For an unlisted style, follow the SKILL's evidence-first fallback rather than forcing a match.
