# Контролы Wien

## Объявление

Числа автоматически создают крутилки, boolean — On/Off. Слайдер выбирается
комментарием справа или над обычной числовой переменной:

```js
const cutoff = 1200 // @slider fire 20..20000
const pan = 0       // @slider vertical -1..1
const speed = 1     // @slider 0.25..4

// @slider vertical 0..1 fire
const wet = 0.15
```

Диапазон, стиль и направление идут в любом порядке. Каждый аргумент необязателен:
направление — `horizontal` (также `default`) или `vertical`, стиль — имя вроде
`fire`, диапазон — `min..max`. Пропущенные стиль и направление — стандартные.
Повторные или конфликтующие аргументы диагностируются.

Диапазон задаётся явно; без него используется 0..1 для любого имени переменной.
Все числа конечные, min < max, значение внутри диапазона. Имя стиля сохраняется,
но темы ещё не реализованы. Поддерживается только `//@slider ...`;
старые отдельные range/vertical и slider(fire) удалены.
`//@ignore` скрывает контрол, действует над переменной или справа.

В новом стартовом проекте controls-demo.strudel открывается автоматически.

## Enum

Только автоматическое определение по выбору поля, без специальных аннотаций:

```js
const Wave = Object.freeze({
  Sine: "sine",
  Triangle: "triangle",
  Saw: "sawtooth",
})
const waveform = Wave.Triangle
```

Объект описывает набор, отдельная переменная — выбор. В UI показаны все подписи
вдоль дорожки, активный вариант отмечен ручкой. Выбор Saw записывает Wave.Saw
в исходник; музыкальный код получает строку "sawtooth".

Набор — верхнеуровневый const Object.freeze({...}) в том же файле, объявленный
до использования. Минимум два поля с уникальными строковыми либо конечными
числовыми значениями одного типа. Геттеры, методы, spread и вычисляемые ключи
не допускаются; числовые ключи исключены ради однозначного порядка позиций.
Строковые подписи с пробелами доступны через Wave["Soft sine"]. Объект сам по
себе контрол не создаёт. //@ignore скрывает выбранную переменную.

## Мультивыбор с порядком

Реализовано. Пустой выбор, вертикальная панель, перестановка строк и аннотация
`multi` сохраняют состояние в исходнике.

```js
const Fx = Object.freeze({
  Echo: "echo",
  Crush: "crush",
  Chorus: "chorus",
})

const effects = [Fx.Echo, Fx.Chorus]
```

Массив хранит включённые варианты и последовательность их применения.
Непустой массив ссылок на поля одного enum автоматически создаёт мультивыбор.
Один элемент тоже даёт мультивыбор. Все варианты остаются видны.

Основной сценарий создания — пользователь сам пишет непустой массив.
Для изначально пустого выбора пользователь сам указывает набор вариантов.

```js
let effects = [Fx.Echo]
let otherEffects = [] // @multi Fx
```

### Начальное расположение

Без `order` строки всегда идут в порядке объявления полей enum.
Порядок элементов исходного массива влияет на выполнение кода.
При действии в панели выбранные ссылки записываются в порядке строк сверху вниз.
Если массив пустой и указан только `@multi Fx`, все строки выключены.

### Одна вертикальная строка на вариант

Слева ручка перетаскивания, затем чекбокс и название. Клик по чекбоксу или
названию меняет On/Off. Ручка меняет порядок. Выключенная строка приглушена,
остаётся читаемой и доступна для перетаскивания. Названия переносятся внутри
строки. Длинный список прокручивается вертикально.

### Включение и выключение

- Включение оставляет строку на месте и вставляет ссылку в массив согласно
  порядку включённых строк сверху вниз.
- Выключение удаляет ссылку из массива. Строка сохраняет позицию.
- Можно выключить последний вариант. Редактор записывает [] и добавляет
  `// @multi Fx`, если аннотации ещё нет. Контрол остаётся на панели.
- Повторное включение возвращает вариант на сохранённую позицию в цепочке.
- Пустой массив с `@multi Fx` означает, что все варианты выключены.
  В примере с reduce остаётся исходный паттерн.
- Пустой массив без аннотации не создаёт контрол, поскольку набор неизвестен.
- Дубликаты в выбранном массиве и ссылки на разные enum диагностируются.

### Перестановка и сохранение

Перетаскивать можно включённые и выключенные строки. Во время перетаскивания
показываются перемещаемая строка и место вставки. Порядок и исходник фиксируются
после отпускания. Escape отменяет перемещение. У края панели включается
вертикальная автопрокрутка.

Полный порядок хранится в необязательном аргументе аннотации.

```js
const effects = [Fx.Echo, Fx.Chorus] // @multi Fx order=Echo,Crush,Chorus
```

`order` содержит ключи всех вариантов, включая выключенные. Массив содержит
только включённые ссылки в том же относительном порядке. При перетаскивании
обе записи обновляются одной транзакцией. Перемещение выключенной строки
может изменить только аннотацию.

Редактор добавляет `order` после пользовательской перестановки строк.
Обычные переключения On/Off сохраняют порядок объявления enum и меняют массив.
Очистка выбора добавляет `@multi Fx`. Существующая аннотация сохраняется
при последующих действиях, в том числе при пустом выборе.

Для ключей с пробелами и запятыми используются JSON-кавычки, например
`order=Echo,"Soft chorus",Crush`. Аннотация также может стоять над переменной.

### Ручные правки и изменения enum

Массив задаёт включение и порядок выполнения. Расположение строк определяется
`order`, а при его отсутствии — объявлением enum. Ручное изменение массива
обновляет галочки. Следующее действие в панели записывает массив в порядке строк.

Новые поля enum добавляются в конец списка выключенными. Имена удалённых полей
пропускаются в метаданных порядка. Если удалённое поле остаётся в выбранном
массиве, показывается ошибка. Чтение и восстановление UI сами по себе
не переписывают код. Следующее действие в панели сохраняет актуальный порядок.

### Клавиатура, Undo и воспроизведение

Tab переводит фокус между строками, Space переключает выбранную строку,
Alt + стрелка вверх/вниз переставляет её на одну позицию. Фокус следует за строкой.
Одна перестановка или одно переключение создаёт одну операцию Undo, включая
изменения массива и комментария. Ручная правка, отмена, повтор и открытие файла
восстанавливают состояние из кода.

Включение и выключение обновляют звучание сразу существующим механизмом Wien.
Перестановка применяется после отпускания строки. Остановленный транспорт
остаётся остановленным. Значения автоматически сохраняются вместе с исходником.

## Управление и проверка

Имя переменной — заголовок. У слайдера значение видно постоянно, минимум слева
или внизу, максимум справа или сверху. Вертикальная дорожка отцентрована
независимо от подписей. У enum все подписи видны, при нехватке места есть
горизонтальная прокрутка.

Слайдер: перетаскивание, колесо, стрелки с шагом 1/1000 диапазона, Shift для
точности, Alt для ускорения, Home/End для границ. Enum: клик по подписи,
перетаскивание с привязкой к позициям, стрелки, Home/End.

GUI меняет исходник и при воспроизведении переисполняет код без сброса часов.
При Stop изменения не запускают звук. Значения — обычные primitive, импортов
и обёрток нет. Разбор настроек не исполняет пользовательский код.

Общий пример: [examples/sliders.strudel](examples/sliders.strudel).
В нём waveform меняет тембр, cutoff — яркость, pan — стереопозицию, speed —
скорость, wet — реверберацию, gain — громкость, enabled — включение звука.

Кнопка, визуальные темы и выбор диапазонов по умолчанию отложены.
