# Wien

Локальная музыкальная среда на Strudel. Прототип: Electron, React, TypeScript,
React Arborist, pnpm и Biome. Интерфейс ориентирован на тёмную тему приложения Codex.

## Запуск

Команды ниже выполняются из корня репозитория. Все pnpm-скрипты, зависимости,
lockfile и конфигурация клиента находятся в `client/`.

Нужны Node.js 22.12+ (рекомендуется Node 22 LTS), pnpm и just.
Полный Xcode для запуска и сборки этого клиента не требуется.

```sh
pnpm --dir client install
just run-client
```

`pnpm install` также скачивает исполняемый файл Electron через `postinstall`.
Это нужно и в новом worktree: его `node_modules` устанавливаются отдельно.
Если зависимости установлены с `--ignore-scripts`, выполни
`pnpm --dir client exec install-electron` перед запуском.

Открывать в VS Code нужно **корень репозитория**. Задача **Wien: Run client**
запускает приложение из корня; default task **Wien: Run** также запускает сервер
в соседнем терминале. Установите рекомендованное расширение **Biome**:
форматирование и организация импортов включены при сохранении поддерживаемых файлов.

```sh
just test          # проверки клиента и Rust-сервера
just build-client  # сборка в client/out
```

Дополнительные команды из корня репозитория:

```sh
pnpm --dir client format   # применить форматирование и исправления Biome
pnpm --dir client package  # приложение в client/release (на macOS — .app)
```

`pnpm --dir client package` создаёт локальную неподписанную сборку. Подпись сертификатом
Developer ID и notarization для распространения здесь не настроены.

## Работа с проектом

- При первом запуске открывается **First session** с пятью примерами.
- Файлы из explorer открываются во вкладках в верхней полосе. Нажатие на вкладку
  переключает редактор, крестик или `⌘W` / `Ctrl+W` закрывает её с сохранением правок.
  Открытые сниппеты могут играть одновременно в фоне; играющие табы отмечены
  анимированной границей. Закрытие таба останавливает только его плеер.
  Вкладки прокручиваются по горизонтали; стрелки, Home и End переключают их с клавиатуры.
  При переключении проекта список вкладок очищается.
- Меню проекта слева сверху позволяет создать проект или открыть папку на диске.
- Explorer показывает папки и файлы `.strudel` / `.js`. Есть поиск, создание,
  переименование, перенос мышью или через меню, удаление в системную корзину.
- Код автоматически сохраняется через 650 мс после правки. `⌘S` сохраняет сразу.
- `⌘Enter` запускает / обновляет текущий сниппет, `⌘.` останавливает его,
  `⌘⇧.` останавливает все сниппеты (также кнопка Stop all). На Windows/Linux — `Ctrl`.
  Каждый сниппет запускается со своим темпом и с начала; общей синхронизации тактов пока нет.
- `⌘,` открывает ассистента возле курсора и переводит ввод в поповер. Enter отправляет
  запрос, Shift+Enter добавляет строку, Esc закрывает поповер и возвращает фокус.
  В поповере только последний краткий ответ, без истории чата. Правки применяются
  сразу к текущему файлу, сохраняются и отменяются одним Cmd+Z в редакторе.
  Выделение передаётся как контекст вместе со всем файлом. Для AI запусти
  `just run-server`; модель и мастер-промпт настраиваются в `server`.
- На macOS `⌘Q` сохраняет правки и завершает приложение. Закрытие окна оставляет
  приложение запущенным; при ошибке сохранения закрытие и выход отменяются.
- При ошибке обновления сниппета продолжает играть его предыдущий успешно
  запущенный код. Переключение проекта останавливает все плееры.
- **Graph View** внизу левого меню открывает отдельный таб с зависимостями всего
  проекта. Стрелка идёт от используемого сниппета к файлу, который его импортирует.
  Несвязанные файлы тоже показаны. Узлы можно перемещать, граф — масштабировать.
- **View in Graph View** в меню сниппета открывает граф с фокусом на этом файле.
  Двойной клик по узлу или его кнопка открытия возвращают к редактору.
  Повторное переключение на таб сохраняет положение камеры; `⌘W` закрывает граф.
- Граф учитывает несохранённый код, обновляется при открытии и по Refresh graph.
  Ошибки импорта отмечаются на соответствующих узлах. Код для построения графа
  не исполняется. Отображение — React Flow, автоматическая раскладка — Dagre.
- Папку проекта можно открыть в файловом менеджере через меню проекта.

Стандартные банки Strudel подключаются автоматически при подготовке плеера:
drum machines (включая `RolandTR808` и алиасы `TR808`, `TR909`), Uzu drumkit,
Salamander piano, VCSL, mridangam, Uzu wavetables, стандартная подборка Dirt-Samples
и GM soundfonts (`gm_piano` и другие). Например, без дополнительного `samples(...)`:

```js
s("bd sd,hh*8").bank("RolandTR808");
```

Карты звуков включены в сборку; аудиофайлы и soundfonts загружаются из сети только
при первом воспроизведении соответствующего звука. Стартовые сниппеты используют
встроенные синтезаторы и играют без сети. Пользовательские наборы по-прежнему
подключаются через `samples(...)` и могут переопределять стандартные звуки.

Снимок карт и алиасов находится в `src/renderer/src/standard-samples.json`;
регистрация — в `standard-sounds.ts`. Источник состава банков и подборки
Dirt-Samples — [prebake Strudel](https://codeberg.org/uzu/strudel/src/branch/main/website/src/repl/prebake.mjs)
(AGPL-3.0-or-later); карты получены с `https://strudel.b-cdn.net/`.
Для обновления снимка используйте JSON-карты из этого prebake и сохраняйте
CDN base URL каждого банка. Сами аудиофайлы не входят в сборку; их лицензии
указаны в исходных библиотеках (Salamander piano — CC BY 3.0, Alexander Holm;
VCSL — CC0, Versilian Studios).

Проверка банков с реальной загрузкой сэмплов и измерением аудиосигнала:
`pnpm --dir client test:banks` (нужен доступ к CDN). Проверяются `tr909`,
`RolandTR909` и `tr808`, включая kick, closed hat и open hat.

## Контролы

Правая панель **Controls** показывает крутилки для числовых `var`, `let` и `const`
на верхнем уровне активного файла, в том числе экспортируемых. Поддерживаются
числовые литералы и арифметика (`108 / 4`, `-0.25`, `2 ** 3`), без выполнения
вызовов функций или вывода типов из других переменных. Переменные внутри функций
и блоков не показываются. Импорты собираются рекурсивно в отдельные плашки файлов;
булавка закрепляет текущий файл как мастер при переходе к исходникам.

Тяните крутилку вверх / вправо или используйте стрелки. Шаг одинаков для всех
значений: `0.01` на пиксель или нажатие стрелки, с `Shift` — `0.001`, с `Alt` — `0.1`.
Наведите курсор на крутилку и прокручивайте колесо: вверх — увеличить, вниз —
уменьшить. Обычный шаг — `0.02` на 100 пикселей прокрутки или 3 строки;
плавная прокрутка трекпада меняет значение пропорционально расстоянию.
`Shift` уменьшает шаг в 10 раз, `Alt` увеличивает в 10 раз. Над крутилкой
прокрутка меняет значение, над остальной панелью — прокручивает список.
Под крутилкой показано значение с точностью до пяти знаков
после запятой; точное число можно изменить в коде. Ограничений min/max нет,
принимаются конечные числа. Значения от крутилки округляются до пяти знаков. Изменение заменяет исходное числовое выражение
значением в редакторе, попадает в Undo и автоматически сохраняется.

Во время воспроизведения крутилки автоматически пересчитывают сниппет и его
импорты, заменяя паттерн без перезапуска транспорта. Побочные эффекты кода при
этом выполняются снова. На остановленном транспорте контролы только меняют код;
первый запуск по-прежнему через Play. Обычный набор текста требует Update.

Крестик добавляет `//@ignore` над объявлением (в объявлении через запятую — перед
выбранной переменной). Удалите комментарий, чтобы вернуть крутилку. Пока код
содержит синтаксическую ошибку, контролы не показываются. Кнопка справа в верхней
полосе скрывает и возвращает панель.

### Группы из объектов

Объявите `let voice = {gain, cutoff, enabled}` на верхнем уровне файла:
распознанные контролы появятся только внутри группы `voice`, в порядке ссылок
в объекте. Работают также `var`, `const` и экспортируемые объявления. Поддерживаются
только короткие ссылки на контролы из того же файла; обычные объекты, алиасы,
spread и вычисляемые свойства не создают группы.

Вложенные группы запрещены. Каждый контрол входит максимум в одну группу:
при конфликте первая группа по порядку объявления сохраняется, следующая получает
локальную ошибку. Ошибка не скрывает остальные контролы. Группы сохраняются в
панели импортирующего мастера, а изменение значения обновляет звучание.

Поиск учитывает название группы. ПКМ по заголовку → **Go to declaration** открывает
объект, ПКМ по контролу — исходную переменную. Перетаскивание и `Alt+↑` / `Alt+↓`
внутри группы меняют порядок ссылок в объекте; перенос между группами недоступен.
Заголовок занимает фиксированную строку, длинные имена обрезаются; одиночные
контролы резервируют такую же строку для сохранения сетки.

Пример с группами во вложенных и общих импортах: `examples/controls-playground/`.

### Слайдеры через аннотации

```js
const cutoff = 1200; // @slider fire 20..20000
const pan = 0; // @slider vertical -1..1
const speed = 1; // @slider 0.25..4

// @slider vertical 0..1 fire
const wet = 0.15;
```

Комментарий ставится справа от переменной или отдельной строкой над ней.
Три необязательные настройки можно писать в любом порядке: диапазон `min..max`,
стиль вроде `fire` и направление `vertical` / `horizontal` (`default` — синоним
горизонтального). Пропущенное направление — горизонтальное, пропущенный стиль —
стандартный. Повторные и конфликтующие настройки показывают ошибку.

Диапазон задаётся через `min..max`; если он не указан, используется `0..1`.
Значение и границы должны быть конечными числами, `min < max`, значение внутри
границ. Произвольный код для чтения настроек не исполняется.

Переменная остаётся обычным числом, импортов нет. GUI меняет только её значение,
сохраняя комментарий. `//@ignore` работает сверху и справа и имеет приоритет.
Без аннотаций работают прежние автоматические контролы.

Стрелки меняют значение на 1/1000 диапазона, `Shift` уменьшает шаг в десять раз,
`Alt` увеличивает. `Home` / `End` выбирают границы. Доступны перетаскивание и колесо.

### Автоматический enum

```js
const Wave = Object.freeze({
  Sine: "sine",
  Triangle: "triangle",
  Saw: "sawtooth",
});
const waveform = Wave.Triangle;
```

Выбор поля замороженного объекта автоматически создаёт переключатель вдоль
подписанных позиций. Ключи — подписи, значения — строки или числа для кода.
Сам объект не создаёт контрол. При выборе Saw редактор записывает `Wave.Saw`;
`waveform` остаётся обычной строкой. Аннотации enum и фабрики не требуются.

Поддерживаются верхнеуровневые `const`-объекты `Object.freeze({...})` в том же
файле, объявленные до использования: минимум два варианта, уникальные значения
одного типа (строки или конечные числа). Геттеры, методы, spread, вычисляемые
ключи, числовые ключи и смешанные типы не определяются как enum. Сложные
выражения и пользовательские функции не исполняются ради определения списка.
Поддержан выбор по строковому ключу (`Wave["Soft sine"]`) для подписей с пробелами.
`//@ignore` скрывает выбранную переменную, не меняя набор вариантов.

Можно нажать на подпись или перетащить ручку; стрелки переключают варианты,
Home/End выбирают первый/последний. Выбор при воспроизведении обновляет Strudel
без сброса транспорта, при остановленном транспорте звук не запускается.

### Мультивыбор

```js
const effects = [Fx.Echo, Fx.Chorus];
let emptyEffects = []; // @multi Fx
```

Массив полей одного enum создаёт вертикальный список с галочками. По умолчанию
строки идут в порядке объявления enum. Можно выключить все варианты — редактор
добавит `@multi Fx`, чтобы пустой массив сохранял список доступных вариантов.

Ручка слева перемещает включённые и выключенные строки. После перестановки
полный порядок сохраняется в аннотации, а выбранные ссылки — в массиве.

```js
const effects = [Fx.Echo, Fx.Crush]; // @multi Fx order=Echo,Crush,Chorus
```

Space переключает строку, Alt + стрелка вверх/вниз меняет её положение.
Escape отменяет перенос. Перестановка применяется после отпускания мыши
и отменяется одной операцией Undo вместе с изменением аннотации.

В новом стартовом проекте автоматически открывается `controls-demo.strudel`: пример
с крутилкой, On/Off, enum, горизонтальными и вертикальными слайдерами.
Нажмите Play и меняйте контролы во время звучания. Пример использует встроенный
синтезатор и работает без сети. Его копия в репозитории —
[examples/sliders.strudel](../examples/sliders.strudel).

### Hydra

В редакторе под кодом отображается компактный предпросмотр Hydra. Пример —
[examples/hydra.strudel](../examples/hydra.strudel): нажмите Play, чтобы запустить
визуальный паттерн вместе с аудиопаттерном на встроенном синтезаторе, без загрузки
сэмплов из сети. Предпросмотр принадлежит своей вкладке и скрывается, когда вкладка
неактивна; остановка или закрытие вкладки, а также переключение проекта освобождают
её renderer, не затрагивая звук в других вкладках. Обновление файла без Hydra
удаляет его предпросмотр. Поддерживается стандартный Hydra DSL, кроме `detectAudio`
и `feedStrudel`; внешние скрипты не загружаются.
См. [официальное руководство Strudel по Hydra](https://strudel.cc/learn/hydra/).

## Связанные сниппеты

Файл с экспортами отмечен иконкой пакета, обычный сниппет — иконкой кода.
Меню **⋯** в редакторе и explorer содержит **Make exportable / Remove exports**:
переключатель добавляет `export default` к последнему выражению с паттерном либо
убирает экспорты, сохраняя сам код. Для преобразования код должен быть синтаксически
корректным; несколько `$:`-дорожек сначала нужно объединить через `stack(...)`.

Перетащите `glass.strudel` из explorer в редактор `first-light.strudel`:
источник автоматически получит default export, а после последнего существующего
импорта добавится новый `import` (если импортов нет — в начало файла).
Повторное перетаскивание не дублирует импорт, совпадающие имена
получают числовой суффикс. Внутри explorer перетаскивание перемещает файлы по папкам.
Импортированный паттерн нужно явно включить в композицию:

```js
import glass from "./instruments/glass.strudel";

setcpm(108 / 4);
stack(glass, note("c2*4").s("sine").gain(0.3));
```

Поддерживаются default, именованные и namespace-импорты, включая вложенные
зависимости. Например, файл может экспортировать `export const glass = notes =>
note(notes).s("sine")`, а другой — использовать `import { glass } from './glass.strudel'`.
Для самостоятельного прослушивания такого модуля добавьте `export default glass("c4")`.

При Play / Update зависимости перечитываются с диска и вычисляются один раз за
обновление. Default-паттерн можно слушать отдельно; старые файлы с последним
выражением без экспорта тоже работают. Вызовы `setcpm` / `setcps` импортированных
сниппетов не меняют темп композиции: транспортом управляет запускаемый файл.
Переименование и перемещение через explorer обновляет пути статических импортов.

Импорты должны быть относительными, с расширением `.strudel` или `.js`, внутри
проекта. Циклы, реэкспорты (`export … from`, `export *`) и импортируемые `$:`-дорожки
пока не поддерживаются. Ошибки показывают проблемный файл; синтаксические ошибки
также содержат позицию. При неудачном обновлении продолжает играть предыдущий паттерн.
Изменения зависимости вступают в силу при следующем Update мастер-файла.

Проекты — обычные папки с текстовыми файлами. Приложение запоминает последнюю
папку в `workspace.json` внутри Electron `userData`; там же находится стартовый
проект. UI не получает Node.js: операции доступны через узкий preload API и IPC.
Скрытые каталоги, `node_modules` и символические ссылки в explorer не показываются.
Кнопка обновления перечитывает дерево после внешних изменений. Изменения открытого
файла на диске обнаруживаются перед сохранением: приложение сохраняет правки
в редакторе и сообщает о конфликте вместо перезаписи.

## Структура

```text
src/main/       # Electron, работа с локальными проектами
src/preload/    # типизированный мост IPC
src/shared/     # общий контракт
src/renderer/   # React, explorer, редактор и плеер Strudel
```

Компоненты находятся в `src/renderer/src/components/<Component>/`: рядом лежат
`<Component>.tsx` и `<Component>.module.css`. Условные и составные классы
собираются через `classnames`. Общие кнопки и индикаторы переиспользуются через
`composes` из `styles/common.module.css`.

Цвета интерфейса: `src/renderer/src/styles/theme.css`.
Глобальные базовые стили: `src/renderer/src/styles/global.css`.
Стартовые сниппеты: `src/main/starter.ts`.

Расширенная проверка реального Electron-окна:

```sh
pnpm --dir client test:smoke
```

Она использует временный проект, проверяет сигнал аудиодвижка с выключенным
звуком, сохранение и операции через UI. Удаление тестовой папки проверяется
через настоящую системную корзину. Путь к снимку окна печатается в терминал.
Отдельный сценарий ассистента использует локальный mock-сервер без токенов и
проверяет передачу контекста, автофокус, применение/Undo, ошибки, отмену и защиту
правок, сделанных во время запроса. Настоящая модель в smoke-тестах не вызывается.
В `test:smoke` также входит Hydra-сценарий: проверяются WebGL-кадры, независимое
воспроизведение вкладок и очистка предпросмотра при остановке, закрытии и смене проекта.

Отдельная проверка dev-запуска (без production-сборки):

```sh
pnpm --dir client test:dev-hydra-smoke
```

Она запускает настоящий `pnpm dev` с временными `userData` и кешем Vite,
проверяет видимый редактор и пиксели Hydra при холодном и повторном старте.
В `electron.vite.config.ts` для оптимизатора зависимостей задано
`global: "globalThis"`: браузерная зависимость Hydra `right-now` обращается к
Node-имени `global`. Без этой настройки dev-рендерер падает до появления UI,
хотя production-сборка может работать.

Сценарий фонового воспроизведения проверяет два одновременных тона в аудиосигнале,
независимую остановку, закрытие и переименование играющего таба, историю редактора,
отмену отложенного запуска, анимацию границ и reduced motion.
